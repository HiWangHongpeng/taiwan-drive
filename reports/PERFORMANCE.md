# 渲染診斷

受限於 Chromium 154、SwiftShader 軟體 WebGL。所有比較使用 1280×800、DPR 1、抗鋸齒開啟、暫停起點視角，ready 後觀察 45 秒；保留初始生成及全部慢幀，不換算玩家 FPS。CPU render 是同步 JS 提交耗時，沒有 GPU 計時查詢，不能當 GPU frame time。

舊凍結版按全圖材質合併，實測起點提交 421023 三角形、41 次繪製；14000 個樹木實例在兩個全圖包圍盒內。原「距離裁減」未成立。

同幾何／材質的有界實驗：256m 分塊提交 178923 三角形，卻增加至 1144 調用，CPU render 中位由 0.9ms 增至 14.2ms。改用較粗 512m 分塊，加上只剔除完全超出霧範圍的塊，提交 161848 三角形、226 調用、5571 實例；未改霧距、像素比、抗鋸齒、可見幾何或時間步進。未繼續無限調參。

原始幀間隔（含初始生成）中位：baseline 316.6ms；chunk-only 250ms；chunk512-fog 216.6ms。三個實驗的全部原始幀與 CPU renderTimes 在各自 JSON 中；沒有過濾慢幀。這組數字只能反映該軟體渲染環境與取景。

新版另加地形網格、真實地塊細節與植被，不能與同幾何分塊實驗混為一個單變量性能提升。最終版本採樣在後節分列。構建時用空間索引減少地形／植被的全圖掃描；逐幀只有車附近道路查詢、有限空間塊可見判斷、UI、物理與渲染，沒有逐幀重建整片地形或掃描全部 OSM 地物。

舊去程 2103 個原始幀全部保留；中位 266.6ms、p95 約 533.4ms、最大 17849.2ms。活動牆鐘 562.694s、模擬 374.983s、丟棄 187.700s。不能稱流暢。真實桌面硬體 GPU 的幀率、音質與人類手感仍待驗證。

受到修整／HMR干擾的早期診斷未用於穩定配對比較；倉庫保留上述三個有界比較及最終採樣。

## 最終新版採樣

同一固定條件的最終新版：ready 7112ms，場景生成5478.5ms；360繪製、576593三角形、8679提交實例，總24000個實例（11000樹冠+11000樹幹+2000灌木）分126組、1146個Mesh。幾何368／紋理4。道路中心地形間隙最小0.00958m、細水面相對提交地形最大0.035m、建築底面未支撐間隙最大0m（不是建築真實高度驗證）。

全部128個原始幀：中位350ms、p95 650ms、最大5499.852ms；CPU提交中位2.9ms、p95 8.4ms、最大138.3ms。沒有排除初始／慢幀。最終新版包含更多地形與植被，三角形超過舊版，整體幀間隔沒有證明改善，不能把分塊單變量實驗當成最終遊戲流暢度。原始數據見perf-final-revised.json。
